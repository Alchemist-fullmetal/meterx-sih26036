# Public Repository & Privacy Policy

## Why the source is not public

MeterX was developed as a Smart India Hackathon project. The working implementation is intentionally kept outside this public showcase repository.

This repository is designed to demonstrate the project without exposing the private implementation.

## What is safe to publish here

- high-level architecture
- general feature descriptions
- public demo URL
- screenshots that contain no secrets or sensitive user data
- technology stack
- problem statement reference

## Do not commit

Never commit any of the following:

- `.env` files
- database connection strings
- JWT / session secrets
- Vercel tokens
- API keys
- service-account credentials
- real user information
- private SIH documents
- database dumps
- production logs containing personal data
- internal source-code archives

## Screenshot checklist

Before publishing a screenshot, verify that it does not reveal:

- passwords or tokens
- private email addresses or phone numbers
- real identity documents
- private SIH team data
- browser developer tools containing secrets
- environment variables
- database IDs that should remain private

Use demo/test data whenever possible.
