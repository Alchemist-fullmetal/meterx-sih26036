## Before pushing

1. Open `README.md`.
2. Replace `https://meterix-sih.vercel.app/` with your actual MeterX deployment URL.
3. Add safe screenshots to `screenshots/`.
4. Preview the README on GitHub.
5. Confirm that no source code, credentials, environment files, or private SIH material is included.
